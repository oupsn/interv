## Overview
Interv-platform is a web application built using Go for the backend and React with TypeScript for the frontend. The project is managed using yarn for package management.

## Features
- Backend: Go
- Frontend: React, TypeScript, JavaScript
- Package Management: yarn

## Prerequisites
- Go 1.16 or later
- Node.js 14.x or later
- yarn 1.22.x or later

## Installation

### Backend
1. Navigate to the backend directory:
    ```sh
    cd backend
    ```
2. Install Go dependencies:
    ```sh
    go mod tidy
    ```

### Frontend
1. Navigate to the frontend directory:
    ```sh
    cd frontend
    ```
2. Install yarn dependencies:
    ```sh
    yarn install
    ```

## Running the Application

### Backend
1. Start the Go server:
    ```sh
    go run main.go
    ```

### Frontend
1. Start the React development server:
    ```sh
    yarn dev
    ```

## Building the Application

### Backend
1. Build the Go application:
    ```sh
    go build -o interv-platform
    ```

### Frontend
1. Build the React application:
    ```sh
    yarn build
    ```
